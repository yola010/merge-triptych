# 竖屏照片拼成 16:9 横屏

手机等竖屏拍的照片，想存到电脑或平板上按横屏看，一张张裁、再对齐，很费事。这个小工具把 2 张或 3 张竖图做成一张固定 16:9 的横屏图，方便直接当壁纸、投屏或放进相册横着浏览。

图片不出这台电脑。窗口只负责收路径；真正的裁剪和拼接由本机 PowerShell 调用本地 Python 完成，不上传、不调用任何 AI。

## 它做什么

- **2 张**：左右拼成 16:9。第三格留空即可。
- **3 张**：左、右、第三张拼成 16:9 三联横屏。
- 源图尺寸可以不一样。程序按最短的一张定成品高度，再对每张做居中裁剪，不拉伸变形。
- 成品写在第一张原图的同一文件夹，文件名类似 `原名_16x9.jpg`。已有同名文件时自动加序号，不会覆盖原图。
- 中间临时图放在工具目录里，做完即删。

## 怎么用

1. 准备带 tkinter 的 Python，并安装依赖：

   ```powershell
   pip install -r requirements.txt
   ```

2. 打开 `merge_gui.py`，把开头的 `PY_IMPL` 改成你这台电脑上已安装 Pillow 的 `python.exe`。

3. 双击 `启动.bat`，或直接运行 `merge_gui.py`。`启动.bat` 默认查找 `%LOCALAPPDATA%\Python\pythoncore-3.14-64`；路径不对就改 bat，或用你自己的 Python 启动窗口。

4. 在资源管理器里选中 2 或 3 张图，按 `Ctrl+Shift+C` 复制路径，回到窗口点「粘贴 2/3 行」。也可以手动填「左图」「右图」。

5. 点「生成 16:9 横屏图」。完成后可用「打开成品」查看。

## 文件

| 文件 | 作用 |
| --- | --- |
| `启动.bat` | 打开图形窗口 |
| `merge_gui.py` | 窗口。把路径交给 PowerShell，再串联下面两个脚本 |
| `resize.py` | 居中裁剪到统一尺寸 |
| `merge.py` | 无缝拼接 |

`resize.py` 和 `merge.py` 也可以单独在命令行使用，预设包括左右两张、三联横屏、上下两张、竖长图，以及 2×2 / 2×3 / 3×3 宫格：

```powershell
python merge.py --help
python resize.py --help
```
